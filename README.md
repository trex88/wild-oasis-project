# The Wild Oasis

An internal hotel management tool using React, Styled Components, and Supabase. Key features include booking management, guest check-in/checkout, cabin editing, and data visualization with Recharts. This project showcases proficiency in building complex web applications with a focus on user experience and data management.

Note:
To ensure the website works as intended, click on the button "Upload all data(guests + cabins + bookings)" inside home page. This needs to be done because the data is manually generated based on your current date.
